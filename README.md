# Gridwar Live

Servidor de juego en tiempo real con integración de TikTok Live, overlay y panel administrativo. El código y las instrucciones de instalación están en [`servidor/README.md`](servidor/README.md). En Windows, inicia el proyecto con [`iniciar-servidores.bat`](iniciar-servidores.bat).
